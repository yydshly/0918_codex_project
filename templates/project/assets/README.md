# 图片与素材

`cover.svg` 是本仓库制作的模板占位图，不是项目实际截图。

实际研究时建议使用以下命名：

- `cover.png` 或 `cover.webp`：主封面，供根 README 和子项目介绍引用。
- `architecture.svg`：架构或流程图。
- `screenshot-<场景英文名>.png`：具体功能截图。
- `demo.gif`：必要时提供简短操作演示。

替换封面后同步修改 README 的图片路径、替代文本和图注。
