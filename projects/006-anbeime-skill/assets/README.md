# 图片与素材

本轮包含本项目原创研究网页的真实浏览器截图。截图不代表上游技能、模型或站群已运行验证；未复制上游图片。

| 文件 | 来源与说明 | 检查条件 |
| --- | --- | --- |
| `understanding-map.svg` | 原创能力总览：定位、19类方向、执行链路、价值判断；本地矢量排版 | 2160×3600，分类与研究数据逐项核对 |
| `understanding-map.png` | 由同名原创 SVG 渲染的高清长图，非上游截图 | 2160×3600，已检查文字与版面 |
| `cover.png` | 原创研究导览首页，含 HTML/CSS 内容关系示意 | Edge 无头浏览器，1500×1100 |
| `websites.png` | 原创关联网页导览，选中“聊天演示”说明 | Edge 无头浏览器，1500×1100 |
| `mobile.png` | 原创研究首页的手机布局 | Edge 无头浏览器，390×844，整页截图 |

生成方式见 [verify-demo.mjs](../code/verify-demo.mjs)。已查看三张截图，检查文字可读性、排列与裁切；自动交互检查记录见 [browser-qa.json](../notes/evidence/browser-qa.json)。

后续若增加图片，应记录来源、许可、对应版本，并明确区分概念说明图、模拟数据和真实运行截图。

能力总览最初尝试内置 ImageGen，两次均因服务网络错误失败，没有采用生成图。最终以[原生绘图脚本](../code/build-understanding-map.py)输出 SVG 并由浏览器导出 PNG；未使用 API/CLI 备用模式。最初的[内容与构图提示](../notes/image-prompt.txt)作为创作记录保留，最终文字以 SVG 与绘图脚本为准。
