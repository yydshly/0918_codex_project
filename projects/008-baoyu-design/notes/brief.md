- 浅灰紫工作台，白色阅读区域，紫色强调；原创拾页品牌，系统中文字体。
- A 杂志卡片：封面与双列卡片，引导发现。
- B 专注列表：缩小封面，单列高密度阅读索引。
- C 结构线框：弱化色彩，用虚线标出信息边界。
- 原型使用同一组样本与状态，提供分类、搜索、收藏、已读、新增及删除自建文章。
- 可调品牌色、圆角和字号，组件使用同一套 CSS 变量。状态保存在浏览器。
- 微型设计系统仅覆盖本次所需的两个组件，不宣称是完整企业组件库。
- 4 页简短产品演示：场景 → 三种方向 → 工具链分步动画 → 能力与边界。
