# 拾页 · Reader Kit

这是 008 baoyu-design 能力演示中原创的微型设计系统，并非上游自带品牌。参考上游 Reader App 示例需求，围绕阅读、收藏和筛选建立三种界面方向。编译、检查、导入和预览由上游原版工具执行。

## 内容与视觉规范

中文动作直截了当：保存文章、标为已读、清空筛选。示例文章均为本项目原创演示内容，不代表实际抓取或推荐。界面以白色阅读区域、深墨色文字和紫色动作构成。品牌色 #5144ce，主文字 #222338。色彩变量见 tokens/foundation.css；间距 8/16/24px，圆角默认 14px。阴影仅用于工作台浮层；主题变化通过 CSS 变量覆盖，不在组件内硬编码主题色。

字体使用系统界面字体及 Microsoft YaHei；没有下载品牌字体，没有字体文件依赖。正文字号 16px，辅助文字不低于 12px。文章阅读页采用衬线标题和宽松行距。按钮悬浮轻微变暗、按下位移 1px；不添加循环动画。线框方向隐藏内容封面色彩并采用虚线边界，杂志方向采用双列卡片，专注方向采用紧凑列表。

## 组件与素材

- Button：主动作、次级动作、低强调动作及禁用状态。
- Tag：分类、辅助信息、成功状态。
- 图标由演示页面中少量原创线条图标提供，不作为第三方图标系统发布。无 emoji、摄影或生成图片。封面用 CSS 几何图形表达文章分类，不冒充真实素材。
- foundations.html 展示颜色与排版；components/core/index.html 展示两个真实编译组件。
