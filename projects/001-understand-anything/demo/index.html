常见情况

命令没有被识别

安装后重启 CLI / IDE；在目标仓库打开新会话。也可以直接说“使用 understand 技能分析当前项目”。Codex 的技能前缀是 $，Claude Code 通常使用 /。

仓库很大，第一次分析太久

先分析一个子目录。首次分析需要阅读源码并生成语义内容，可能消耗较多模型额度；本研究没有测量大型项目的耗时和费用。

只想让同事查看图谱

共享已经生成的图谱目录，使用上游独立 viewer；不要求同事再次生成语义内容。源码查看还需要对应项目文件。

npx https://github.com/Egonex-AI/Understand-Anything/releases/latest/download/understand-anything-viewer.tgz /path/to/analyzed/project

一跳关系，不是完整影响链

修改 payment.ts 后，订单函数出现在受影响列表中，间接依赖它的入口函数没有出现。核心算法的结果不等于所有运行时风险。

此固定版本的上游 Dashboard 两种搜索模式调用同一个 Fuse 搜索引擎。核心库虽有向量搜索类，界面仍未接入。

解析结果 ≠ 自动理解已验证
