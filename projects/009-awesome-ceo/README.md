# 009 · Awesome CEO

Awesome CEO 是一份面向创业者与管理者的人工精选链接清单。通过 README 分类和少量推荐语，帮助读者寻找资料、选择阅读入口并跳转原文。

收录融资、创业、产品、销售、营销、管理、招聘、财务，以及书籍与课程、扩展资料、CTO / TPM 相关资源，共 11 个主题、85 条资料、86 个内容链接。资料形式包括文章、指南、问答、书籍、课程、案例、框架、清单、模板、计算工具、演示与视频。

对我们当前的软件能力与技术实现研究，直接参考价值较低；可作为需求验证、早期获客和团队管理等业务知识的备查目录，按需阅读即可，无需继续技术深挖或集成。

上游固定版本只有 `README.md` 与 `LICENSE`，没有应用程序、AI Agent、Skill、API 或经营自动化模块。目录中列出的计算器、投资人目录和模板均由外部网站提供。

## 实现原理

```text
维护者选择资料 → README 按主题组织 → GitHub 展示目录与链接
                                         ↓
读者提出具体问题 → 找到分类 → 跳转外部资料或工具 → 自己判断与执行
```

内容层由标题、外链、部分作者署名和短评构成。展示层利用 Markdown 标题与锚点导航；Git 保存文档修改记录。仓库没有自建搜索、自动抓取、推荐排序、知识库检索或工作流执行代码。

外部计算器负责计算，外部模板站提供模板，读者负责填入真实信息并判断适用性。复制 README 只能获得目录与说明，不会同时获得外部服务或全文内容。

## 如何使用

1. 先明确一个问题，例如“如何验证产品需求”，再进入对应分类。
2. 选择一至两条最相关资源，在原始站点确认作者、日期、适用情境和访问条件。
3. 将阅读结果整理为自己的访谈提纲、实验方案、招聘问题或会议议程。
4. 执行后记录结果；这里的产物是使用建议，上游并不自动生成这些材料。

无需安装运行时、依赖或 API 密钥。可直接浏览[固定版本 README](https://github.com/kuchin/awesome-ceo/blob/89f761c2af903066500e1a0c33c33cf36873cdf6/README.md)，也可阅读本地保存的[上游文档快照](notes/evidence/upstream-readme.md)；访问外部资料仍需要网络及目标站点要求的权限。

## 使用价值与边界

对我们当前的直接参考价值较低，主要是业务知识与阅读入口备查。遇到需求验证、寻找首批客户、组织团队等具体问题时再查阅即可。技术实现较简单，没有需要接入现有开发流程的功能模块；可参考按问题分类、保留来源与短评的资料整理方式。

本次核验时，上游主分支最新提交为 2023 年 2 月。长期方法可供研究，市场案例、融资条件和外部服务状态应在实际使用时重新核查；这不等于所有外链内容都停留在同一日期。分类覆盖也不均衡，例如融资有 24 条，而销售仅 1 条。

已验证文件结构、原始文档、许可证、分类和条目统计，以及本项目中文网页的完整性与交互；没有逐一访问外链、登录外部服务、试用计算器或验证经营效果。已制作真实网页截图并接入本地展厅构建，未发布到公网。
