# 收录与编号约定

## 编号和排序

- 使用 `001-short-name` 格式：至少三位数字编号、小写英文短名，单词用连字符分隔。
- 从 `001` 递增；新项目使用历史最大编号加一，编号不足三位时补零。
- 编号表示收录顺序，不表示质量排名或研究优先级。
- 项目改名、暂停或归档时保留编号；删除后的编号不复用。
- 根 README 的索引与图览按编号的数值升序排列。超过 `999` 后使用 `1000` 等编号，继续按数值排序。
- 模板不是研究项目，不占用编号。

## 目录职责

```text
README.md                         # 总摘要、有序索引、代表截图
projects/
└── 001-short-name/
    ├── README.md                 # 介绍、上游来源、启动方式、结论、截图
    ├── assets/                   # 截图、架构图、演示 GIF 及来源说明
    ├── notes/
    │   └── research.md           # 分析过程、实验记录、问题和结论
    ├── code/                     # 本项目实验或二次开发代码（可选）
    └── demo/
        └── README.md             # Web 演示说明（可选）
docs/                             # 总项目的维护与部署约定
templates/project/                # 可复制的研究模板
```

`code/` 与 `demo/` 可以按实际技术栈调整；依赖、构建配置和运行说明由每个子项目独立维护。没有具体需求前，不在根目录引入统一前端框架或包管理器。

## 新增一个项目

1. 查看根索引和 Git 历史，确定下一个编号。
2. 复制模板到 `projects/<编号>-<英文短名>/`。
3. 将模板中的 `待填写` 等提示替换为实际信息，删除不适用内容。
4. 记录上游仓库链接、上游许可证、研究时的 tag 或 commit；尚未核实时明确写“待核实”。
5. 在根 README 索引添加一行。第一次收录时删除“暂无研究项目”这一行，并更新首页当前状态说明。
6. 有真实截图后替换封面占位图，在子项目和根 README 添加对应图片及图注。
7. 运行项目后填写验证结果；部署成功后才添加可访问的演示链接。

PowerShell 示例（名称和编号仅作示例，执行前先确认目标目录不存在）：

```powershell
Copy-Item -LiteralPath templates/project -Destination projects/001-project-name -Recurse
```

macOS / Linux 示例：

```sh
cp -R templates/project projects/001-project-name
```

根索引条目示例：

```markdown
| 001 | [项目名称](projects/001-project-name/) | 一句话研究摘要 | 研究中 | 未部署 |
```

## 进度与完成标准

| 进度 | 含义 |
| --- | --- |
| 待研究 | 已记录来源和研究目标 |
| 研究中 | 正在阅读代码或进行实验 |
| 已验证 | 已按记录的环境完成核心验证，并写明结论与限制 |
| 暂停 | 暂时停止，保留原因和后续计划 |
| 已归档 | 本轮研究结束，保留成果供后续参考 |

研究进度与部署状态分开记录。“已验证”不等于“已上线”，未部署时直接写“未部署”。

## 图片与记录

- 封面优先使用 `assets/cover.png` 或 `assets/cover.webp`；其他图片用能表达内容的英文短名。
- README 使用相对路径，并为图片填写有意义的替代文本和图注。
- 根 README 只放每个项目最有代表性的一张图，更多图片放在子项目内。
- 模板 SVG 明确标为占位图，不能作为真实运行结果。添加实际截图后修改图片引用，可删除占位图。
- 在 `assets/README.md` 记录图片来源；外部图片和代码遵循原作者许可。
- 研究结论标注对应版本和验证条件，区分实测结果与推测。
- 不提交密钥、本地环境文件、依赖目录或大体积构建产物；必要配置提供不含秘密的 `.env.example`。

## 上游代码管理

优先记录上游链接和固定版本，只提交本次研究需要的实验代码、补丁与文档。确需引入第三方源码时，在子项目中说明引入方式、版本、许可证和修改范围，并保留必要声明；不要直接把带 `.git` 的嵌套克隆放入项目目录。
